## 1. 概述

一个像素风网页小游戏：玩家控制一个人物，在一间学校图书馆里自由走动，寻找并投喂藏在各处的 10 只猫咪。投喂后猫咪会吃东西、冒爱心，好感度满后还会开心地跟随玩家一小段路。

**没有目标、没有时间限制、没有结局**——这是一个逛图书馆撸猫的治愈小玩具。

## 2. 决策记录

| 决策点 | 结论 | 理由 |
|---|---|---|
| 项目目的 | 休闲 vibe coding 成品 | 重点在快速做出好玩、可分享的东西，不在学习游戏开发 |
| 规模 | 小而美：一张地图 + 走动 + 投喂 | 先跑通、先好玩 |
| 场景 | 学校图书馆（室内，单张地图） | 氛围感强、范围可控、"图书馆的猫"本身有味道 |
| 视觉风格 | 像素风 | 免费素材多、风格统一容易 |
| 目标感 | 纯治愈，无目标无结局 | 玩家自发的"找齐 10 只猫"即探索乐趣 |
| 技术方案 | 纯 HTML + Canvas + 原生 JS | 零依赖零构建，双击 `index.html` 即玩，代码全透明，迭代最顺手 |
| 素材策略 | 第一步程序化像素画跑通玩法；第二步（可选）换 CC0 素材 | 不让找素材卡住进度 |

## 3. 玩法设计

### 3.1 视角与画面

- 俯视角 2D 像素风
- Canvas 逻辑分辨率 480×320（tile 16×16，共 30×20 格），CSS 放大 2 倍显示，`image-rendering: pixelated` 保持像素锐利

### 3.2 人物

- WASD / 方向键移动，四方向朝向，走路 2 帧动画
- 书架、桌子、墙等家具阻挡（碰撞）

### 3.3 猫咪（10 只）

每只猫有：名字、一句话性格、领地位置（在图书馆地图上分散分布）。

- 部分猫好找（窗台、借阅台旁），部分藏在深处（书架夹缝、桌子底下）
- 猫的日常状态机：**闲逛**（领地小范围踱步）⇄ **打盹** 循环切换
- 玩家走近时，猫转向玩家方向（小反应）

### 3.4 投喂交互（核心循环）

1. 玩家进入投喂距离 → 猫头顶冒气泡提示「E 投喂」
2. 按 E → 一碟猫粮落在猫面前的地上（投喂按距离判定：猫可以待在玩家走不上去的地方，如窗台、书架顶；猫吃食时若食物在不可达格，吃到距离足够近即视为吃到）
3. 猫踱过去低头吃（吃食物动画约 1~2 秒）
4. 头顶冒爱心粒子 +「喵♪」音效（音效可后置）
5. 每只猫 5 颗心好感度，每次投喂 +1 心
6. **喂满 5 心后**：该猫开心地跟随玩家走一小段路，然后心满意足回领地打盹（此后好感度保持满，可继续投喂，反应重复）

食物无限供应，不做资源管理。

### 3.5 氛围

- 图书馆元素：书架、阅览桌椅、窗台（带窗外光）、绿植、台灯、借阅台
- 轻柔 BGM（后期可加，非必须）
- 无菜单、无失败、无存档

## 4. 技术设计

### 4.1 文件结构

```
vibe-game/
├── index.html        # 入口：canvas 元素 + 加载脚本
├── style.css         # 页面居中、深色背景、像素放大渲染
├── js/
│   ├── main.js       # 游戏循环 + 键盘输入 + 人物（移动/碰撞/动画）
│   ├── cats.js       # 10 只猫的数据 + 状态机 + 投喂/好感度逻辑
│   └── map.js        # 图书馆地图数据 + 绘制 + 碰撞表
└── assets/           # 预留：后续替换用素材（精致 sprite、音效）
```

3 个 JS 文件各管一摊：改地图只动 `map.js`，改猫只动 `cats.js`。

### 4.2 游戏循环

`requestAnimationFrame` + delta time。每帧顺序：

```
读输入 → 更新人物 → 更新猫 → 绘制（地图 → 猫碟食物 → 猫 → 人物 → 爱心粒子/UI 气泡）
```

### 4.3 地图与碰撞

- `map.js` 中用字符画（ASCII 矩阵）定义 30×20 格地图，直观可编辑：如 `#` 墙、`B` 书架、`T` 桌子、`.` 地板、`W` 窗台
- 由字符画生成两张数据：绘制层（每个格子画什么）+ 碰撞层（哪些格子不可通行）
- 人物移动时查碰撞表（无物理引擎）

### 4.4 猫状态机

```
闲逛 ⇄ 打盹
  ↓（玩家投喂）
走向食物 → 吃 → 冒爱心 → （若好感满）跟随玩家一小段 → 回领地 → 打盹
```

每只猫的关键数据：领地中心坐标、当前状态、好感度（0~5）。

### 4.5 素材（第一步：程序化像素画）

- 所有图形第一版全部用代码绘制：`Canvas` 填色块 + 16×16 像素矩阵定义猫/人物造型
- 像素矩阵以字符串数组写在代码里（如猫的一帧 = 16 行字符串，每字符代表一个色块），直观、可随手调
- 跑通且好玩后，第二步从 Kenney / itch.io 找 CC0 素材替换，只换绘制层不动逻辑

### 4.6 验证方式

- 每个实施阶段完成后，用 Playwright（webapp-testing）打开页面截图，检查渲染、碰撞、动画状态
- 玩法乐趣由用户亲自试玩判断

## 5. 明确不做（本期边界）

- 无音效/BGM 也可接受（音效列为后期增强，不阻塞成品）
- 无移动端触屏支持（键盘操作）
- 无存档（刷新重来，符合小玩具定位）
- 无多地图/室外场景
- 不做精致素材（属于第二步换皮，可另开任务）

## 6. 后续可扩展（不在本期范围）
