# 图书馆室外场景实施计划

**目标：** 从中庭南门进入夜晚前庭，返回中庭；室外播放《安妮的仙境》，馆内播放卡农。

**调用链：** `maps/*.js` → `MapKit` → `main.js` 场景切换 → `Sound` → 页面 BGM 元素。

1. 为室外地图、门目的地及安全落点增加配置测试，确认新测试先失败。
2. 新建 `maps/outside.js`，并在 `tiles.js` 与 `map.js` 中加入室外地砖、草地、树、路灯、长椅、外墙及入口的图例与画法。
3. 在 `main.js` 注册场景，将中庭南门接到室外。室外入口返回中庭南门内侧，避免在门格上反复传送。
4. 为 `Sound` 增加曲目切换测试，确认先失败；以单个 audio 元素在卡农和《安妮的仙境》之间切换，保留静音状态与首次按键启动机制。
5. 更新资源加载与游戏说明；运行完整单元测试并在浏览器中检查室外画面、碰撞、往返与音乐。
