# zdw 随机学生 NPC 任务清单

## 目标与表现

新增名为 `zdw` 的考研学生。地中海发型、背包和复习资料用于识别角色，采用独立的精细像素帧。首次及每轮离场后有 35% 概率出现，未出现时每 12 秒重试；出现后从前庭进图书馆，复习 24–40 秒，再出馆。

在室外看到 128 像素范围内的咪咪后追赶。咪咪害怕他，会优先逃向草丛；已经被追踪时，躲起来仍可能被抓到。动作依次为伸手抓起、抓后腿短暂倒提、放下，随后咪咪逃开；至少 24 秒内不重复抓取。角色不穿越障碍，离开场景时解除持有关系，保留咪咪好感和食物。

## 实现任务

- [ ] 新增 `src/npc/zdw.js`：概率出现、进出馆、复习、寻路追踪与抓放状态。
- [ ] 新增 `src/data/zdw-sprites.js` 和 `src/npc/zdw-render.js`：青年地中海发型、步行与复习、抓起／倒提／放下动画。
- [ ] 修改 `src/npc/mimi.js`：恐惧优先于投喂，被抓期间停止自行移动；放下后恢复躲藏和后续投喂。
- [ ] 修改 `src/npc/index.js`、`src/main.js`、`src/render.js`：角色注册、传递当前咪咪、被抓时只绘制一次。
- [ ] 在 `deploy/tests/zdw.test.js`、`deploy/tests/mimi.test.js`、`deploy/tests/npcs.test.js` 验证概率、完整行为、草丛与障碍、食物优先级、切场景清理。
- [ ] 运行 `npm test`、`npm run build:pages`，检查实际浏览器中的发型、抓持接触点和完整动作。

## 接口约定

`createZdw(maps, rng)` 创建可离场的唯一角色，`updateZdw(npc, dt, mimi, rng)` 更新行为。聚合更新的第 5 个参数为当前室外咪咪，其他场景传 `null`。`Mimi.update` 最后增加可选威胁角色参数；`Mimi.capture(mimi, holder)` 与 `Mimi.release(mimi, point)` 管理猫的持有状态，`drawZdw(ctx, npc)` 负责持有期间的猫和人物组合绘制。

当前请求为新增功能；完成后交付本地效果和验证结果。
