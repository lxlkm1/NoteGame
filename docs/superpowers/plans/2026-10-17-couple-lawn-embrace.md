# 情侣草坪坐姿与环抱实现计划

**目标：** 情侣散步停下时有概率走到空旷草坪，男生先坐下、女生坐到他腿上，脸红加深、男生双臂收紧，停留后起身散步。

**实现方式：** 在情侣行为中新增寻草地和坐姿阶段；为坐姿使用一张组合像素帧，明确腿部、裙摆以及手臂的前后遮挡。保留女生白裙、刘海、小猫发饰和男生黄发、深色外套；通过女生低头、手放膝上、逐渐脸红以及男生主动收拢双臂表达人物性格。

**技术：** 原生 JavaScript、Canvas 像素矩阵、Node 测试。

## 任务

- [x] `src/npc/couple.js`：随机选取可到达且空间足够的草坪；加入坐下、坐腿上、环抱、抱紧、起身和重新散步阶段。
- [x] `src/data/couple-lawn-sprites.js`：制作五张 64×56 组合动作帧，统一男生脚部锚点 `(40, 56)`。
- [x] `src/npc/couple-render.js`：按动作选择组合帧，只绘制一次，避免人物重复和手臂遮挡错误。
- [x] `deploy/tests`：验证仅在草坪坐下、无草坪时正常散步、动作顺序与退出，以及绘制一次和颜色合法。
- [x] 预览全部动作帧和实际地图画面，检查坐腿上、脸红和双臂收紧可辨认。
- [x] 运行测试、构建和差异检查。
