# 📚 图书馆喂猫 · Library Cats

一个像素风治愈小游戏：在夜晚的图书馆和前庭闲逛，找到 11 只猫，投喂它们。

## 玩法

- **WASD / 方向键** 移动
- 走近猫咪，按 **E** 投喂
- 从中庭南门按 **E** 前往夜晚的图书馆前庭；在室外入口按 **E** 返回馆内
- 前庭左右的树丛里有机会遇到奶牛猫咪咪；离它 6–8 格、面向可走的地面按 **E** 放食物，再退远等它出来吃
- 每只猫有 5 颗心的好感度；馆内猫喂满后会跟随，怕人的咪咪仍会躲进树丛
- 首次按键自动响起卡农 BGM；按 **M** 静音 / 恢复（HUD 显示 🔊/🔇）
- 在室外 BGM 切换为《安妮的仙境》，回馆后恢复卡农
- 没有目标，没有结局。猫开心，你开心。

## 运行

直接双击 `index.html` 即可（无需安装任何东西）。

或者起个本地服务：

```bash
python3 -m http.server 8137
# 打开 http://localhost:8137
```

## 技术说明

纯 HTML + Canvas + 原生 JavaScript，零依赖零构建。
投喂/猫叫/满心跟随/打盹四类事件音效由 Web Audio API 程序化合成，馆内 10 只猫各有专属嗓音基频。
BGM 使用 `assent/` 中的卡农与《安妮的仙境》音频文件，随场景切换。
`npm test` 跑单元测试（地图碰撞 / 精灵尺寸 / 猫状态机 / 音频纯逻辑）。
